Headings

HTML provides six levels of headings, from h1 to h6. They are used to create a hierarchy and organize the content of a webpage.The h1 element represents the main heading, while h2 through h6 represent progressively deeper levels of content.

Paragraph

The p element is used to represent a program of text. Paragraphs help divide written content into meaningful sections and make the structure of information easier to understand.

HTML describes the structure and meaning of content, while CSS can later be used to control its appearance and layout.

Line Breaks

The br element creates a line break without starting a new paragraph. It is useful when a line break is actually part of the content.

Subscript and Superscript

The sub element represents subscript text, while the sup element represents superscript text.They are commonly useful for scientific formulas and mathematical expressions.

Preformatted Text

The pre element represents preformatted text. Whitespace and line breaks inside the element are preserved by the browser.
