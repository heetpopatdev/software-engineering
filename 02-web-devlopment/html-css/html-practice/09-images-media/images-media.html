HTML Images and Media

Images

The img element is used to display an image on a webpage. The src attribute specifies the location of the image that the browser should load.

The src Attribute

The alt attribute provides alternative text for an image.It is useful when an image cannot be displayed and helps people using screen readers understand the purpose or content of the image.

Image width and Height

Width and height can be specified for an image. They provide the browser with information about the intended dimensions of the image.

Figure and Figcaption

The figure element represent self-contained content such as an image,diagram,illustraion or other media. The figcaption element provides a caption describing the figure.

Audio

The audio element allows audio content to embedded into a webpage. The controls attribute provides controls that allow the user to play, pause, and control the audio.

Video

The video element allows video content to be embedded into a webpage. The controls attribute provides playback controls to the user.

Video Attributes

Video elements can use attributes such as controls, muted, loop, and autoplay to control how the media behaves.

Embedding External Content

The iframe element can embed another webpage or supported external content inside the current webpage.

Priority Hints

Priority Hints allow us to tell the browser which resources are more important and should be loaded with higher or lower priority.

High Priority Image

The fetchpriority attribute tells the browser that this image is important and shoud be given higher loading priority.

Low Priority Image

A low-priority resource is less important, so the browser can choose to load it later.

Content Security Policy(CSP)

Content Security policy is a browser security mechanism that controls which sources a webpage is allowed to load resources from.

Example

This page uses CSP to allow images only from this website itself and from data URLs.

If an image tries to load from an unapproved external website, the browser will block it.

Why CSP Is Useful

CSP helps protect websites from loading unwanted or potentially dangerous resources.
