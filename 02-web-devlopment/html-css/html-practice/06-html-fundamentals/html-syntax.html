HTML Syntax and Document Structure

What Is an HTML Element?

An HTML element is a complete part of an HTML document that usually consists of an opening tag, content, and a closer tag. Tags tell the browser what type of content an element contains. For example, a paragraph can be written using the p tag.

In the example <p>Hello World</p> the opening tag is <p>, the content is "Hello World", and the closing tag is </p>. Together, they form an HTML element.

What Are HTML Attributes?

HTML attributes provide additional information about an element.They are written inside the opening tag and usually have a name and a value. For example, the lang attribute in the html element tells the browser the primary language of the document.

Attributes can also be used to identify elements, provide links, describe images, and control other information about an element.Examples include id, class, href, src, and alt.

HTML Document Structure

An HTML document has a basic structure that helps the browser understand the document.The doctype declaration tells the browser that the document uses modern HTML. The html element is the root element and contains the head and body.

The head contains information about the document, while the body contains the content that is displayed on the webpage.

Head and Metadata

The head element contains information about the webpage that is not normally displayed as visible page content. The title element defines the title of the webpage, which can appear in the browser tab.

Meta elements provide metadata about the document. For example, the charset attribute specifies the character endcoding, while the viewport meta element helps the webpage display correctly on different screen sizes.

HTML Comments

HTML comments are notes written inside the code for developers. They are not displyed as normal content on the webpage. Comments can be useful for explaining sections of code or leaving notes for future development.

Whitespace in HTML

Whitespace includes spaces,tabs, and line breaks used in HTML code. Browsers generally ignore extra whitespace when displaying normal text. Devlopers can use whitespace in the code to make HTML easier to read and maintain.

HTML Entities

HTML entities are special codes used to represent characters that have a special meaning in HTML or characters that are difficult to type directly.

Less-than symbol: <

Greater-than symbol: >

Ampersand symbol: &

Copyright symbol: ©
